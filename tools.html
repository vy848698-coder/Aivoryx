Secure file sharing

Best for sending a contract, a design file or a set of scans to a client who will never install anything to receive it.

Email bounces anything worth sending and the free lockers turn your file into an advert with a countdown on it. This does the plain version: upload, get a link, decide how long it lives and who gets past it.

fileshare.aivoryx.com

What it does
  • Encrypts the file on upload, not just the connection

Free, no sign-up Tool 02

Self-destructing secrets

Best for handing over a password, an API key or a bank detail without it living in a WhatsApp thread for the next four years.

The real problem with sending a password over chat isn't the moment you send it — it's that the message is still sitting there long after the person has left the company. This gives you a link that works exactly once and then stops existing.

secret.aivoryx.com
Open the tool The service behind it →
What it does
  • Destroys the secret the moment it's read
  • Keeps nothing readable once the link is spent
  • Expires on a timer even if nobody opens it
  • Notifies you the second it's viewed
  • Leaves the secret out of email and chat history entirely
What it isn't
  • A password manager — it's for handover, not storage
  • Recoverable — if it's read by the wrong person, it's read
  • Proof of who opened it, only that somebody did
  • A substitute for rotating the key afterwards

Storing passwords is the easy half. The half that actually gets people breached is not knowing which of them you've reused, which are guessable, and which were in a leak two years ago. This watches for all three and tells you.

vault.aivoryx.com
